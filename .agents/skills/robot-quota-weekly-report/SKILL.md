# 外呼机器人用量日报与周报

## 输入

- 单一 Sheet，第一行每列是日期，例如 `7月10号`。
- 每个非空数据单元格格式为 `• [机器人ID]机器人名称(最高XX.XX%)`。
- 输入只有一个日期列时生成日报；多个日期列时生成周报。
- 输入内容已经是超量名单，Skill 不重复进行 100% 阈值判断。

## 执行

从仓库根目录运行：

```powershell
线索变量脚本\glm-proxy\venv\Scripts\python.exe .agents\skills\robot-quota-weekly-report\scripts\generate_report.py 输入.xlsx 输出.png
```

可通过第三个参数覆盖标题，通过 `--mode daily` 或 `--mode weekly` 强制指定模式。

脚本同时生成同名 `_stats.json`，用于核对每日数量、频次和 Top3。

## 周报口径

- KPI：全周超量总次数、日均超量机器人数、单日最高超量数、连续全周超标机器人数。
- 每日柱状图按周期内相对高低分为红、橙、绿三档。
- 高频名单保留周期内出现至少 3 次的机器人。
- 每日 Top3 按最高百分比降序。

## 日报口径

- 展示指定日期超量机器人数、最高用量、最高用量机器人和全部超量明细。
- 当日无超量记录时明确显示正常状态，不生成虚假数据。

## 边界

- 不读取或回显账户密码、token 和 Cookie。
- 如果表格结构不符合约定，先检查实际列和单元格，不静默忽略格式错误。
- 平台统计源代码位于 `线索变量脚本/glm-proxy/robot_quota/report_renderer.py`，Skill 必须复用该实现，避免日报和周报口径漂移。
