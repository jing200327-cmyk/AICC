# 日度月度汇总表数据计算说明

## 数据来源总览

| 数据 | 来源文件 | 说明 |
|------|---------|------|
| 全月线索明细 | 当日下载的 `data/{date}/原始数据/{公司}-outcall-线索明细-{date}.xlsx` | 爬虫设置时间范围为当月初至当天，包含全月全部线索 |
| 当日话单 | 当日下载的 `data/{date}/原始数据/{公司}-aicc-话单-{date}.xlsx` | 爬虫设置时间范围为当月初至当天，包含全月话单 |
| tracking | `_tracking/{公司}_{月份}.json` | 每次跑日报时自动记录，每条包含：呼叫通次、新增线索量、新增线索接通量、有效线索量 |

## 字段定义与计算逻辑

### MTD 板块（月至今累计）

| 字段 | 数据来源 | 计算方式 |
|------|---------|---------|
| 累计线索量 | 当日全月线索明细表（截止至 date） | 筛选 `线索下发时间 <= date` 后的行数 |
| 接通量 | 同上 | 同上范围中 `通话状态` 含"已接通"的行数 |
| 有效线索量 | 同上 | 同上范围中 `线索状态` 为"有效"的行数 |
| 呼叫通次 | 全月话单表（截止至 date） | 筛选 `结束时间 <= date` 后的行数 |
| 平均呼叫通次 | — | 呼叫通次 ÷ 累计线索量 |
| 接通率 | — | 接通量 ÷ 累计线索量 |
| 接通有效率 | — | 有效线索量 ÷ 接通量 |
| 整体有效率 | — | 有效线索量 ÷ 累计线索量 |

> **说明**：线索相关指标（累计线索量/接通量/有效线索量）取自**全月线索明细表中截止至 `--date` 日期**的线索。例如用 17 号的文件处理 16 号的数据时，只统计月初～16 号的线索，而非全表。
> 
> 这样确保回溯历史日期时 MTD 不包含未来日期的线索。`通话状态` 仍反映截至全月表导出时的最新状态。
> 
> 呼叫通次直接从**话单源表**中筛选 `结束时间 <= date` 计算，不依赖 tracking 逐日累加，确保回溯历史日期时口径一致。话单中每行记录一通呼叫。

### Daily Report 板块（当日详情）

| 字段 | 数据来源 | 计算方式 |
|------|---------|---------|
| 新增线索量 | 每日日报 | 当日筛选项：`线索下发时间 == 当天` 的线索数 |
| 昨日全天对比 | `_tracking/` JSON | 取 tracking 中**前一天**记录的 `新增线索量` |
| 新增线索接通量 | 每日日报 | 当日新增线索中，匹配到话单且 `通话状态` 含"已接通"的线索数 |
| 新增线索呼叫通次 | 原始话单表 | 当日话单按 `结束时间 == 当天` 筛选后的总行数。**不经过去重，不经过线索匹配** |
| 平均呼叫通次 | — | 新增线索呼叫通次 ÷ 新增线索量 |
| 接通率 | — | 新增线索接通量 ÷ 新增线索量 |
| 昨日全天对比（接通率） | `_tracking/` JSON | 用前一天记录的 `新增线索接通量 / 新增线索量` 重算 |
| 接通有效率 | — | 有效线索量 ÷ 新增线索接通量 |
| 整体有效率 | — | 有效线索量 ÷ 新增线索量 |
| 昨日全天对比（整体有效率） | `_tracking/` JSON | 用前一天记录的 `有效线索量 / 新增线索量` 重算 |

> **说明**：昨日对比数据不是直接从 tracking 取原值，而是取前一天的分子/分母后重算比率，确保对比口径一致。

## 数据流转路径

### 爬取阶段（recorder.py）

```
外呼系统(outcall-manage)
  → 登录 → 设置线索开始日期为本月初 → 查询 → 导出线索明细
  → 保存到 data/{date}/原始数据/{公司}-outcall-线索明细-{date}.xlsx

呼叫系统(aicc-poc)
  → 登录 → 设置话单开始时间为本月初 → 查询 → 导出话单
  → 保存到 data/{date}/原始数据/{公司}-aicc-话单-{date}.xlsx
```

### 处理阶段（process_clue_report.py → daily_summary.py）

```
读入话单文件 → 按 结束时间 <= date 筛选 → 计算 MTD 呼叫通次
               → 按 结束时间==当天 筛选 → 计算当日呼叫通次 = len(df_call)
读入线索文件 → 按 线索下发时间 <= date 筛选 → 计算 MTD 累计指标
               → 按 线索下发时间==当天 筛选 → 匹配话单 → 生成日报文本

调用 generate_daily_summary():
  1. 读取 _tracking/{公司}_{月份}.json
  2. 写入当天记录（呼叫通次 + 日报数据）
  3. MTD 呼叫通次 = monthly_stats["累计呼叫通次"]（话单表截止 date，不依赖 tracking）
  4. 昨日对比 = tracking 中前一天记录
  5. 生成 Excel
```

## tracking 文件格式

`_tracking/长沙_2605.json`:

```json
{
  "260501": {
    "呼叫通次": 188,
    "新增线索量": 91,
    "新增线索接通量": 42,
    "有效线索量": 3
  },
  "260502": {
    "呼叫通次": 166,
    "新增线索量": 52,
    "新增线索接通量": 26,
    "有效线索量": 11
  }
}
```

该文件逐日追加，由 `.gitignore` 排除，不进入版本控制。

## Excel 输出模板

`data/{date}/汇总表/{公司}_日度月度汇总表_{date}.xlsx`

表结构：
- 第1行：表头（蓝色底 #4E83FD）— 业务场景 / 单位 / {公司名}
- MTD 板块：规模指标 + 检测指标
- Daily Report 板块：规模指标 + 检测指标 + 昨日全天对比
